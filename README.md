# モダンデザイン・ショールーム (8大Webデザインスタイル比較)

Google Antigravityを用いて開発された、8大モダンWebデザインスタイルをインタラクティブに比較・体験できるショールームWebサイトです。

## 収録されているデザインスタイル

### A. 先進トレンド・個性派（4種）
1. **🪟 グラスモフィズム (Glassmorphism)**: すりガラス効果、オーロラ背景、高級感のある浮遊感
2. **🍱 Bento Grid**: Apple/現代SaaS（Linear/Vercel等）風の幾何学的タイルレイアウト
3. **🎨 ネオ・ブルータリズム (Neo-Brutalism)**: 3.5pxの極太黒枠、ハードドロップシャドウ、レトロポップ
4. **⚡ サイバー・ダーク (Cyber / Futuristic)**: 漆黒の宇宙背景、ネオングロー、HUDターミナル

### B. 誰もが見慣れた王道・定番（4種）
5. **🏢 コーポレート・トラスト (Corporate & Trust)**: 大手企業・金融・Yahoo!風。信頼の濃紺、4px角丸、端正な長方形
6. **🛍️ メガEC・マーケット (Amazon/楽天風)**: 黄色〜オレンジの購買CTAボタン、★4.9レビュー、セールバッジ
7. **📱 マテリアル・デザイン (Material You / Google風)**: M3パステルトーン、大きな角丸、スタジアム型ピルボタン
8. **📰 エディトリアル・メディア (日経新聞/Medium風)**: 格調高い明朝体（Noto Serif JP）、生成りの紙面質感、直角美

---

## 閲覧・動作確認方法
特別なビルドツールやサーバー起動は不要です。
1. リポジトリをクローンまたはダウンロードします。
2. `index.html` をお好みのブラウザ（Google Chrome, Edge, Safari等）で開くだけで即座に動作します。

---

## ファイル構成
- `index.html` : サイトの骨格（ナビゲーションバー、ヒーローセクション、特徴グリッド、フッター）
- `style.css` : 8大スタイルそれぞれのCSS変数・レイアウト・アニメーション定義
- `script.js` : スタイル切り替え処理、シチュエーション写真・テキストの動的更新、カウンター動作
